## ⚙️ Backend Details

The backend for **Vonto – Coffee Order App** is being built using:

- 🟢 **Node.js** – for server-side logic  
- 🍃 **MongoDB** – for storing coffee menu, user details & orders  
- 🔒 **Express.js** – for API routes & authentication

> ⚠️ Backend development is currently **in progress** and will be updated soon.

Once completed, the Flutter app will communicate with this API for real-time order management and data persistence.
